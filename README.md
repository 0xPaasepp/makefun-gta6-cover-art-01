Velvet Heat — Cover Studio turns your photos into GTA-style multi-panel poster cover art, offline in the browser. A dual engine — ink/poster mode with face-aware halftone, and a clean photographic mode — across 6 genuinely distinct templates, 5 grades, per-panel crop/position/rotate, and one-click export of all three post sizes (1080 × 1080, 1080 × 1350, 1920 × 1080) as PNGs.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no sign-in, no upload, no network requests at runtime. Load the sample photos (made with an image model, no real people) or add your own, pick a template, drag panels to crop, edit the title, and hit **Export all 3 sizes**.
